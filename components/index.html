Components

Six components, rendered by the real stylesheets. Copy the markup, copy tokens/tokens.css and components/components.css, and you have the register. Every value resolves back to a token, so retheming is one file. See the README for the position map and CUSTOMIZE.md for moving it.

Log

The component this register exists for, so it goes first. Fixed tracks for time and level, the message taking the rest. The level is the only column allowed to be colored, because it is the only one the eye scans down. Every level carries its word as well as its color. Below 768px the message drops to its own row rather than being squeezed into twelve characters.

Button

Four variants and two sizes. Only the accent variant is filled, and a page gets one of it: a second fill in the accent color puts two marks meaning "here" on the same screen. Destructive is outlined rather than filled, so the dangerous button never outranks the default one.

Panel

Elevation here is a hairline and a ground step, never a shadow: a shadow on a near-black ground either fails to render or renders as a smudge. The lead variant is the one place the edge glow appears, and it takes the panel's own color, so a failing panel would glow red from the same declaration. One per screen. The flush variant drops the body padding so rows can run edge to edge.

Input

Four states: default, focus, invalid, disabled. The field sits on the page ground rather than the surface, so it reads as a hole in the panel rather than a tile on it. Focus is a solid accent outline and not a glow, because a glow is a color cue and color alone is not a focus indicator. Body text holds at 16px, which is what stops iOS Safari zooming the page on focus.

Lowercase, dashes, no spaces.

Chip

Five statuses. Each variant sets exactly one property, its color; the tint, the rule and the dot all derive from it with color-mix, so adding a sixth status is one line. Ok is the accent itself rather than a second green, because two greens a few degrees apart read as a rendering fault. The solid modifier reverses to ground-on-fill for a chip that has to survive on a busy row, where every status clears 7:1.

Nav

One bar with a prompt-chevron lockup, inline links above 768px, and a disclosure panel below it. The panel is a <details> element, so the pattern ships without a line of JavaScript and keeps working when scripts fail. The glow layer

Two tiers of text glow, two of edge glow, and the prompt and cursor marks. Both tiers are built on currentColor, so one pair of declarations serves every status. Nothing below 14px carries a glow: the halo spreads into the counters of the letterforms and closes them, so at small sizes glow costs legibility outright. The contrast in this theme holds with every glow switched off, which is the test.

Palette, measured

A dark theme has three grounds, not one, and the raised ground is the least forgiving of the three. Each figure below is the worst of the three, which is the one that has to clear AA. A theme measured only against the page background passes its own audit and still fails inside a hovered row, which is where dense UI puts most of its text.
